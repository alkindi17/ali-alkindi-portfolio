## Overview

**Baitak** is a chalet-rental marketplace for the Kuwaiti market. We built it as our graduation group project at the National Software Academy, Cardiff University. Renters find and book chalets in a mobile app. Hosts manage their listings and admins run the platform from two web portals.

![Baitak App Features](/data/projects/mdx/img/baitak-1.png)

## My role

We were a team of five working in Scrum. I chose the architecture and tech stack, set up both codebases, and reviewed most of the team's code.

## Tech stack

The renter app uses React Native and the web portals use Next.js, both written in TypeScript. Supabase runs the backend and database, and Stripe takes payments. We tested with Jest, designed in Figma, and kept the code on GitLab.
